## 🌿 Weekly Deep Dive

### 🔍 Week 1-3: Searching & Sorting
* Learned the difference between $O(n)$ and $O(\log n)$ searching.
* Implemented various sorting techniques and analyzed their stability and time complexity.

### ⚡ Week 4-5: Divide & Conquer
* Mastered the "Divide, Conquer, and Combine" strategy.
* Optimized sorting using Merge and Quick sort for large datasets.

### 🌐 Week 6: Graph Algorithms
Implemented graphs using **Adjacency Matrix** to solve:
1. **Path Finding:** Using DFS to check if a route exists between two nodes.
2. **Bipartite Check:** Using BFS with 2-coloring technique to verify graph structure.
3. **Cycle Detection:** Identifying loops in directed graphs using recursion stacks.

## 🚀 How to Use this Repository

Follow these steps to run any algorithm from this repository on your local machine:

```bash
# 1. Clone the Project
git clone [https://github.com/SakshamPantola/DAA-4th-Sem.git](https://github.com/SakshamPantola/DAA-4th-Sem.git)

# 2. Enter the Directory
cd DAA-4th-Sem

# 3. Choose a Week (e.g., Week-1, Week-6)
cd Week-6

# 4. Compile the Code (Replace filename.cpp with actual file name)
g++ filename.cpp -o solution

# 5. Run the Output
./solution
